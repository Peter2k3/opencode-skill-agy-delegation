# Repository Guidance

This repository packages the `agy-delegation` OpenCode skill.

- Keep `skills/agy-delegation/SKILL.md` concise and LLM-first.
- Keep supporting detail in `skills/agy-delegation/references/`.
- Do not add machine-specific home directories, credentials, or local agent/model assumptions.
- Run `python3 tests/test_skill.py` after skill changes.
- Keep README, changelog, and compatibility claims aligned with the skill.
